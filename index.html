MINDSET

Ce qu'on cherche réellement à maîtriser

01

Mécanismes avant outils

Comprendre le protocole, le service, les permissions, l'authentification et la frontière de confiance avant l'outil qui automatise le test.

02

Admin ↔ Attaque ↔ Défense

Pour chaque technologie : configuration normale, erreurs de configuration, exploitation en lab, télémétrie, détection et mitigation.

03

Chaînes, pas vulnérabilités isolées

Apprendre à combiner accès initial, credentials, privilèges, pivoting et mouvement latéral jusqu'à un impact démontrable.

04

Preuves et reporting

Un pentest professionnel se termine par des preuves reproductibles, une analyse de risque et des recommandations applicables.

SPECIALIZATIONS

Chemins possibles après le tronc commun

Il n'existe pas un seul “pentester”. Choisis une direction, garde le tronc commun, puis approfondis.

Comment choisir ?

Tu aimes HTTP, logique métier, APIs → Web / API Tu veux auditer les entreprises → Internal / Active Directory Tu aimes Linux, services, réseau → Infrastructure Tu veux enchaîner plusieurs systèmes avec discrétion → Red Team Tu aimes mémoire, assembleur, binaires → Exploit Development Tu travailles sur AWS/Azure/Kubernetes → Cloud & Containers Tu veux attaquer et améliorer la détection → Purple Team Tu veux applications Android/iOS → Mobile

PRACTICE SYSTEM

La pratique qui transforme les connaissances en compétence

01

Guided

Cours + lab guidé. Comprendre le mécanisme et reproduire proprement.

Objectif : compréhension
02

Assisted

Machine ou challenge avec notes personnelles, documentation permise, pas de walkthrough complet.

Objectif : méthodologie
03

Independent

Cible inconnue. Enumeration, hypothèses, exploitation et PrivEsc sans solution.

Objectif : autonomie
04

Multi-host

Plusieurs machines, credentials réutilisables, segmentation, AD et pivoting.

Objectif : attack chain
05

Professional

Scope, temps limité, preuves, notes, restitution, rapport exécutif et technique.

Objectif : mission réaliste

Cadence recommandée pour quelqu'un qui travaille

40%Labs / machines
25%Fondamentaux & théorie
15%Scripting / automatisation
10%Notes / writeups
10%Reporting / défense

À 8–12 h/semaine : viser environ 12–18 mois pour bâtir une base très sérieuse. La vitesse dépend des compétences réellement démontrées, pas du nombre de vidéos terminées.
