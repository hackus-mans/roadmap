# Offensive Security Roadmap

Site multi-pages conçu pour guider un profil IT / réseau / administration vers un niveau professionnel en pentest.

## Navigation

- `index.html` — accueil et vue d’ensemble
- `roadmap.html` — parcours principal structuré en 4 niveaux
- `tracks.html` — spécialisations possibles
- `resources.html` — références et plateformes
- `roadmap-data.js` — données de la roadmap
- `app.js` — progression locale et interactions

## Parcours

### 01 — Foundations
Linux, Windows, réseau, scripting.

### 02 — Core Pentest
Méthodologie, recon, Web/API, Linux et Windows pentest.

### 03 — Enterprise
Active Directory, services d’entreprise, pivoting, attack chains et reporting.

### 04 — Advanced
Cloud, containers, exploit development et offensive orienté détection.

## Philosophie

- Compréhension > mémorisation
- Enumeration > exploitation
- Mécanismes > outils
- Observation → Hypothèse → Test → Résultat → Interprétation
- Admin ↔ Attaque ↔ Défense
- Une mission se termine par preuves, impact et remédiation

## Déploiement

Le dépôt est publié avec GitHub Pages. Toute modification sur `main` déclenche le workflow de déploiement configuré dans `.github/workflows/pages.yml`.

## Usage responsable

Le contenu est destiné aux CTFs, labs, machines personnelles, plateformes d’entraînement et missions explicitement autorisées.
