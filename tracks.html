SPECIALIZATIONS

Choisir une direction après avoir construit le socle.

Tu peux devenir généraliste solide puis approfondir un domaine. Une spécialisation n’efface jamais les fondamentaux : elle décide surtout où investir le plus de temps.

01
RECOMMANDÉPolyvalent

Pentester généraliste

Le meilleur point de départ pour quelqu’un qui veut maîtriser Web, systèmes et infrastructure avant de se spécialiser.

Priorités
  • Roadmap Core complète
  • Web + Linux + Windows
  • AD + pivoting
  • Reporting
Suivre ce parcours →
02
WEBApplications

Web & API Pentester

Pour ceux qui aiment HTTP, logique métier, APIs, authentification, contrôle d’accès et failles côté serveur.

Approfondir
  • HTTP / browser security
  • PortSwigger + OWASP
  • API / GraphQL
  • Auth & business logic
Choisir après : Foundations + Core Web
03
ENTERPRISEIdentity

Internal / Active Directory

Pour auditer des environnements d’entreprise où identités, permissions, partages, Kerberos et relations AD sont centrales.

Approfondir
  • Windows internals
  • Kerberos / NTLM
  • ACL / AD CS
  • Lateral movement
Choisir après : Windows + Network + Pentest methodology
04
INFRASystems

Infrastructure / Linux

Serveurs, services réseau, Linux, permissions, segmentation, accès distant, tunnels et erreurs de configuration.

Approfondir
  • Linux internals
  • SSH / NFS / SMB / DB
  • Network segmentation
  • PrivEsc & containers
Choisir après : Foundations
05
RED TEAMMulti-host

Red Team

Pour apprendre à atteindre un objectif à travers plusieurs systèmes, avec identité, mouvement latéral, pivoting et compréhension de la détection.

Prérequis sérieux
  • Core Pentest solide
  • AD / Internal
  • Attack chains
  • Detection-aware operations
À choisir tard, pas au début
06
CLOUDModern infra

Cloud & Containers

Identités cloud, IAM, secrets, Docker, Kubernetes, CI/CD et frontières de confiance d’architectures modernes.

Approfondir
  • IAM
  • Containers
  • Kubernetes RBAC
  • CI/CD security
Choisir après : Linux + Web + Identity basics
07
LOW LEVELBinary

Exploit Development

C, assembleur, mémoire, debugging, formats binaires, mitigations et exploitation sur programmes de laboratoire.

Approfondir
  • C / memory
  • x86-64 assembly
  • GDB / WinDbg
  • ROP foundations
Choisir après : programmation + systèmes
08
PURPLEDetection

Purple Team

Transformer chaque technique offensive en exercice de télémétrie, détection, investigation et durcissement.

Approfondir
  • MITRE ATT&CK
  • Sysmon / EDR
  • Sigma
  • Detection engineering
Choisir après : Pentest Core
